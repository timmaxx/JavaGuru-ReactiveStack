The files in this directory are used to demonstrate working with Postman.

Spring security is on for all, except POST!

"Create User" for a new user request will be 201 Created.
"Create User with invalid validation data ..." request will be 400 Bad Request.
And it is good!

And it is good!

"Get Users" request will be 401 Unauthorized.
And it is good!
